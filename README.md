# Proposition RealSpill — Chez Thia (Angré, Abidjan)

Proposition commerciale **indépendante**, dans l'attente de l'accord du propriétaire : elle n'a été ni
commandée ni validée par le restaurant. Rien n'est publié ; ce dépôt doit rester **privé**.

- [`maquette/`](maquette/) — site Next.js + TypeScript + Tailwind CSS : accueil, menu, spécialités,
  galerie, réservations & événements, contact (+ page de transparence `/maquette`).
  Installation, architecture et vérification : [`maquette/README.md`](maquette/README.md).
- [`maquette/INFOS-A-OBTENIR.md`](maquette/INFOS-A-OBTENIR.md) — informations publiques trouvées
  (une seule source, ancienne) et liste de ce qu'il faut obtenir avant toute mise en production.

```bash
cd maquette && npm install && npm run dev   # http://localhost:3000
```
